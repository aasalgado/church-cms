# RhythmAddict Dance Studio

## Brand Guide

---

# Purpose

This document defines the visual identity and design direction of the RhythmAddict Dance Studio CMS.

The goal is **not** to redesign RhythmAddict's brand.

The goal is to modernize the website while preserving the studio's existing identity.

This document serves as the source of truth for all future UI decisions.

---

# Brand Identity

Business Name

RhythmAddict Dance Studio

Brand Personality

- Welcoming
- Energetic
- Modern
- Community-focused
- Professional
- Beginner-friendly

Visitors should feel:

- Excited to learn
- Comfortable attending their first class
- Confident contacting the studio
- Inspired by the community

---

# Logo

Status

Use the official RhythmAddict logo.

Future

The logo should appear consistently in:

- Navbar
- Footer
- Browser favicon
- Social sharing
- Future CMS login page

---

# Photography

Photography should emphasize:

- Real dance classes
- Salsa
- Bachata
- Cumbia
- Ballroom
- Social dancing
- Beginners
- Community
- Smiling students
- Instructor interaction
- Movement
- Warm lighting

Avoid:

- Generic stock photos
- Empty studios
- Static poses
- Church imagery

# Typography

Current

Playfair Display
Inter

Evaluation

Playfair Display feels elegant but may communicate a more traditional or formal tone than desired for a dance studio.

Inter remains an excellent body font.

Future Goal

Evaluate heading fonts that communicate:

- Energy
- Movement
- Confidence

without sacrificing readability.

---

# Iconography

Use icons that reinforce dance and movement.

Examples:

- Music
- Dance
- Calendar
- Clock
- Location
- Phone
- Email

Remove:

- Church icon
- Ministry-related icons

---

# UI Principles

The interface should feel:

Simple

Modern

Inviting

Confident

Avoid unnecessary decoration.

Use whitespace intentionally.

Every section should have a clear purpose.

---

# Content Principles

Speak to beginners.

Avoid jargon.

Keep calls-to-action short and action-oriented.

Use positive, encouraging language.

---

# Future Enhancements

Potential future additions include:

- Testimonials
- Student success stories
- Gallery
- Pricing
- FAQ
- Registration
- Online payments
- Event calendar

---

# Design Philosophy

This project is not intended to copy the current RhythmAddict website.

Instead, it aims to create a cleaner, more maintainable, and more user-friendly experience while preserving the studio's existing identity and brand.
